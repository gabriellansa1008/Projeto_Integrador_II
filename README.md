# Projeto_Integrador_II
Repositório para a Etapa I

## Problema

Em escolas, alunos que produzem desenhos e outros trabalhos artísticos nem sempre possuem um espaço organizado para apresentar suas produções. Muitos deles até expõem sua arte na sala de aula , mas nem todas elas recebem o devido reconhecimento. 

## Solução proposta

Pensando em valorizar a produção artística dos alunos e facilitar a divulgação de seus trabalhos dentro da escola, o projeto **Arte na Escola** será uma plataforma onde alunos poderão criar publicar seus desenhos e ver as publicações de outras pessoas. Além disso, poderão consultar informações sobre os artistas em seus perfis.

## Objetivo geral

Criar uma plataforma simples para divulgação e valorização dos desenhos produzidos pelos alunos dessa instituição escolar.


## Objetivos específicos

- Permitir que alunos publiquem seus desenhos;
- Facilitar a visualização das produções;
- Ampliar a divulgação de diferentes estilos artísticos;
- Apresentar informações básicas sobre os alunos artistas;
- Criar um espaço digital para divulgação da produção artística escolar.

## Público-alvo

O sistema será voltado a todos da escola, sejam alunos, professores ou funcionários.

## Usuários do sistema

### Aluno/Artista

O aluno poderá:

- Criar uma conta;
- Realizar login;
- Publicar desenhos;
- Editar suas próprias publicações;
- Remover suas próprias publicações;
- Visualizar desenhos publicados.

### Visitante

O visitante poderá:

- Visualizar desenhos;
- Visualizar informações sobre os artistas.


## Principais funcionalidades

| Código | Funcionalidade |
|---|---|
| **RF01** | Cadastrar aluno |
| **RF02** | Realizar login |
| **RF03** | Publicar desenho |
| **RF04** | Visualizar desenhos |
| **RF05** | Pesquisar desenho |
| **RF06** | Filtrar por categoria |
| **RF07** | Visualizar perfil do artista |
| **RF08** | Editar publicação |
| **RF09** | Remover publicação |



## Regras principais

- Apenas alunos cadastrados poderão publicar desenhos;
- O aluno deverá estar autenticado para publicar, editar ou remover seus trabalhos;
- Cada publicação deverá possuir título e imagem ;
- O aluno poderá editar ou remover apenas suas próprias publicações;
- Visitantes poderão visualizar os trabalhos publicados;
- Os trabalhos deverão respeitar as regras de convivência da escola.


## Escopo

### Dentro do escopo

- Cadastro de alunos;
- Login;
- Publicação de desenhos;
- Visualização de trabalhos;
- Perfil do artista;
- Edição de publicações;
- Remoção de publicações.

### Fora do escopo

A primeira versão não terá:

- Sistema de comentários;
- Curtidas;
- Mensagens privadas;
- Sistema de seguidores;
- Pagamentos;
- Loja de desenhos;
- Integração com redes sociais;
- Aplicativo para celular.
