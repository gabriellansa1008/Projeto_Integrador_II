# Arte na Escola
Esse sistema funcionará de modo simples , com uma linguagem objetiva e intuitiva, para que todos possam acessá-lo.
Não é necessário login para visualizar as publicações de outras pessoas, mas para publicar o login é obrigatório.
## Tipos de Usuários

### Aluno/Artista

Poderá:

- Criar uma conta;
- Realizar login;
- Publicar desenhos;
- Editar suas publicações;
- Remover suas publicações;
- Pesquisar perfis de artistas.

### Visitante

Poderá:
- Pesquisar perfis de artistas;
- Visualizar desenhos;
- Visualizar informações dos artistas.

##  Escopo

### Dentro do escopo

- Login;
- Publicação de desenhos;
- Visualização;
- Perfil do artista;
- Edição de publicações;
- Remoção de publicações.

### 7.2 Fora do escopo

- Comentários;
- Curtidas;

- Loja de desenhos;
- Integração com redes sociais;

# Requisitos funcionais

### RF01 — Cadastrar aluno

O sistema deverá permitir que o aluno crie uma conta informando seus dados básicos.

### RF02 — Realizar login

O sistema deverá permitir que alunos cadastrados acessem sua conta utilizando e-mail e senha.

### RF03 — Publicar desenho

O sistema deverá permitir que alunos autenticados publiquem um desenho informando título, imagem, categoria e descrição.

### RF04 — Visualizar desenhos

O sistema deverá permitir que os visitantes visualizem os desenhos publicados.

### RF05 — Pesquisar desenho

O sistema deverá permitir pesquisar desenhos por título ou nome do artista.

### RF06 — Visualizar perfil do artista

O sistema deverá permitir que os visitantes visualizem informações básicas do aluno e seus trabalhos publicados.

### RF07 — Editar publicação

O sistema deverá permitir que o aluno altere as informações de seus próprios desenhos publicados.

### RF08 — Remover publicação

O sistema deverá permitir que o aluno remova seus próprios desenhos publicados.



# 9. Requisitos não funcionais

### 1.Usabilidade

O sistema deverá possuir uma interface simples e organizada, facilitando sua utilização pelos usuários.

### 2.Segurança

As funções de publicação, edição e remoção deverão estar disponíveis somente para alunos autenticados.

### 3.Desempenho

O sistema deverá apresentar os desenhos e informações solicitadas de forma adequada durante sua utilização.
